# EventFlow V1.7｜系統建置藍圖版

## 本版目標
依課堂需求，以一頁七階段流程圖解釋 EventFlow 的建置與運作流程。此版以 V1.6 為基底，**不變更資料庫結構或現有報名 API**。

## 新增
- `/blueprint.html`：可於瀏覽器觀看的七階段建置藍圖，支援列印或另存 PDF（A4 橫向）。
- 管理後台側邊選單增加「系統建置藍圖」入口。
- 更新版本標示至 V1.7。

## 七階段
1. 活動建立：主辦者設定活動資訊與名額。
2. 頁面設計：設定品牌視覺與報名欄位（部分進階品牌客製化尚未實作）。
3. 活動展示：公開首頁分類、搜尋與活動詳情。
4. 線上報名：資料驗證、名額確認與提交。
5. 資料庫：SQLite 保存活動、報名、帳號等資料。
6. 後台管理：活動列表、報名審核與資料備份。
7. 活動執行：簽到與出席統計屬後續版本規劃。

## 狀態說明
- 已有基礎：Node.js / Express / SQLite、管理登入、活動建立、公開探索頁、報名、基本審核、備份。
- 待強化：Banner 上傳、Logo／主題客製化、活動模板完善、團體報名、簽到、出席統計。
- 藍圖中的「頁面設計」與「活動執行」代表目標流程，不代表相關所有功能已完成。

## 啟動
需要 Node.js >= 22.13.0。

```bash
npm install
npm start
```

- 活動首頁：http://localhost:3000/
- 管理後台：http://localhost:3000/admin.html
- 系統建置藍圖：http://localhost:3000/blueprint.html

## 課堂 Demo 建議
登入管理後台 → 一鍵建立 Demo 活動 → 前台分類與搜尋 → 點入活動報名 → 後台查看報名 → 打開建置藍圖解釋系統流程。

## 升級提醒
使用既有資料時，先備份舊版 `data` 資料夾，再將資料複製到 V1.7 專案中。不要覆蓋原始備份。
