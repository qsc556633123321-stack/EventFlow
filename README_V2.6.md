# EventFlow V2.6

在 D:\Coding\EventFlow 執行 npm start，開啟 http://localhost:3000，管理後台 /admin.html。Node.js >=22.13（建議目前的 24）。若 3000 已被舊版占用，先在舊視窗 Ctrl+C，再啟動；或 PowerShell `$env:PORT=3001; npm start`。

## 已實作
- 總覽與報表：依活動、報名起迄日篩選；每日趨勢、活動比較、審核候補狀態、出席率及三種 CSV。
- 報名 CSV 包含自訂欄位快照、答案、審核與簽到時間；活動統計 CSV；簽到歷史 CSV。UTF-8 BOM、引號換行處理及公式注入防護。不匯出查詢碼或 QR token。
- 日期依 Asia/Taipei 報名日期（含首尾日），不是活動日期或簽到日期；所有狀態均列入報名總數。出席率以篩選內目前已確認報名人數為分母，已確認且核銷人數為分子；沒有確認人數時顯示 —。歷史取消核銷仍保留於簽到匯出。
- 前台照片封面、活動詳情、表單及後台導覽與報表外觀更新。自訂上傳優先，預設照片失效回退本機 SVG。未修改既有品牌、活動或報名資料。
- V2.5 QR EF25 協定保持相容；SQLite schema 不變。原始碼快照於 upgrade-backups，並非完整資料備份。正式資料與 uploads 未刪改。
