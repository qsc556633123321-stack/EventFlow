# EventFlow V2.3

以 V2.2 原始碼升級，保留既有 SQLite 資料與 V2.2 API。

## 新增
- 活動草稿、取消狀態（管理員可透過既有活動編輯 API 更新；建立表單可選擇）
- 額滿候補選項及候補報名
- 報名成功後提供隨機查詢碼；公開首頁可用編號與查詢碼查詢狀態（舊報名無查詢碼）
- 後台報名搜尋、狀態篩選、批次通過/拒絕、CSV 匯出

## 執行
需要 Node.js >=22.13，於 EventFlow 資料夾執行 `npm install`、`npm start`，開啟 http://localhost:3000 與 http://localhost:3000/admin.html。

## 注意
- 先備份 `data/` 資料夾再升級；此版使用增量資料表遷移。
- 候補不會自動遞補，需由管理員後續人工處理。
- 舊報名資料不具備查詢碼，無法使用公開查詢。
- 公開部署請使用 HTTPS 並設置 COOKIE_SECURE=1。
