# EventFlow V2.8

Windows 本機專案：`D:\Coding\EventFlow`。Node.js 24+。

```powershell
cd D:\Coding\EventFlow
npm install
npm run check
npm test
npm start
```

先停止舊版程序，再啟動新版。前台 [http://localhost:3000](http://localhost:3000)，後台 [http://localhost:3000/admin.html](http://localhost:3000/admin.html)，[系統藍圖](http://localhost:3000/blueprint.html)。不需要 ZIP。
