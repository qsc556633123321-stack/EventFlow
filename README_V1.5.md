# EventFlow V1.5 — UI Foundation

## 啟動
1. 安裝 Node.js 22.13 或更新版本。
2. 在專案資料夾執行 `npm install`。
3. 執行 `npm start`。
4. 開啟 http://localhost:3000/ 或 http://localhost:3000/admin.html。

## V1.5 更新
- 全新響應式管理後台與公開活動頁面。
- Dashboard 活動數量統計、活動列表操作。
- 新增活動的自訂欄位視覺化編輯與即時預覽（文字、長文字、數字、日期、下拉選單）。
- 沿用 V1.4 Express、SQLite、API、帳號與報名審核流程。

## 注意
- 這是課程測試版，不是正式商用版本。
- V1.5 的表單設計器目前支援「建立活動時」配置欄位；既有活動的編輯仍使用 V1.4 簡易修改流程。
- 仍使用原 V1.4 資料庫結構；若要保留舊資料，請先備份舊版 data 資料夾並複製至新版相同位置。
- 字型優先使用 Google Fonts，無網路時會自動退回系統字型。
- 尚未在使用者 Windows 環境進行完整端對端測試。
