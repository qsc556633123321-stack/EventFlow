## Shared member service (B exports)

createMemberPlatform({db,log,bad,hashPass,verifyPass,mailer,uploadsDir}) returns {register(app),auth(req,res,next),optional(req),fromCookie(cookieHeader),notify(userId,data)}.
Cookie ef_member_session is separate from ef_session, HttpOnly SameSite Strict Path=/ Secure when req.secure/COOKIE_SECURE. Use sessions.audience='member' and sha256 rawtoken; csrfFor from security.js. fromCookie resolves/revalidates every time; returns null or {id,email,nickname,publicId,avatarUrl,verified:boolean,csrfToken,sessionHash,sessionExpires}. optional(req) calls fromCookie and returns null/session without throwing. auth attaches req.member and enforces CSRF on writes; unverified may profile/login, but chat and member-linked registration require verified. Existing admin user may opt-in public profile only after correct password during member login, not through anonymous register existing email; verification still required.
