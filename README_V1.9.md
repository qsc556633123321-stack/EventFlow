# EventFlow V1.9｜Demo 插畫與後台分頁

## 新增
- `public/demo/`：六張隨專案附帶的 SVG 活動插畫，離線可用；為 Demo 示意插畫，不是真實活動照片。
- 公開首頁預設使用京都主題插畫，主辦者上傳的 Banner 仍可覆蓋。
- 後台六個獨立工作區：總覽、活動管理、建立活動、報名管理、品牌與圖片、資料備份。側邊選單切換時只顯示該區塊。
- Demo 建立功能同時為六個活動指定示意封面；若同名活動已有自行上傳封面則不覆蓋。

## 啟動
`npm install`、`npm start`，瀏覽 `/admin.html`。管理員登入後選「活動管理」→「建立 Demo 活動」。

## 資料
延續舊版資料時，先備份並複製舊版 `data` 目錄。無需額外資料表遷移。

## 注意
本版未加入外部授權攝影照片；SVG 為本專案生成的示意插畫。請在本機驗證登入、Demo 建立、選單切換、圖片顯示與報名流程。
