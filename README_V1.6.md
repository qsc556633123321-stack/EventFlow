# EventFlow V1.6｜活動探索 Demo

## 啟動
需 Node.js 22.13+（內建 node:sqlite）。在專案根目錄執行：

```bash
npm install
npm start
```

- 前台：http://localhost:3000/
- 後台：http://localhost:3000/admin.html

## Demo 資料
管理員登入後，在「活動列表」按「一鍵建立 Demo 範例活動」。將建立 6 場範例活動，不會覆蓋原有資料；同主辦單位同名範例活動不會重複建立。

## V1.6 內容
- 大型橫幅、活動分類、關鍵字搜尋、活動卡片、詳情彈窗及報名表單。
- 保留 V1.5 後端、資料庫、後台管理及自訂欄位。
- 範例資料由後端 API 寫入 SQLite，不是前端假資料。
- 活動分類目前採用標題/描述關鍵字判斷，後續版本應加入正式 category 欄位。
- Banner/卡片使用 CSS 示意視覺，不依賴外部圖片服務；後續可增加封面上傳。

## 資料移轉
新 ZIP 不包含資料庫。若從 V1.5 升級，先備份 V1.5 的 data/ 目錄，停止舊服務後將其複製至 V1.6 根目錄。請勿在兩個伺服器同時使用同一資料庫。
